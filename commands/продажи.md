# Конвейер «AI-отдел продаж»

Запрошенный шаг: **$ARGUMENTS**

Определи шаг по первому слову аргумента и дальше работай строго по скиллу из таблицы. Скилл содержит всё: порядок действий, схему таблиц, правила проверки и список того, чего делать нельзя.

| Первое слово | Скилл | Что делает |
|---|---|---|
| портрет, icp, клиент | `prodazhi-portret` | переводит описание клиента в машинные фильтры и пишет config.json |
| список, выборка, компании | `prodazhi-spisok` | выборка из реестра МСП ФНС в `data/leads.db` |
| отсев, фильтр, почисти | `prodazhi-otsev` | бесплатный отсев до обогащения, таблица `otsev` |
| обогащение, обогати, сайты | `prodazhi-obogashchenie` | сайт, почта, ФИО руководителя, выручка |
| сигналы, боли, диагностика | `prodazhi-signaly` | диагностика сайта и поводы написать |
| письмо, письма, напиши | `prodazhi-pismo` | письмо на проверенных фактах, таблица `letters` |
| черновики, разложи, почта | `prodazhi-chernoviki` | раскладка писем по черновикам IMAP |
| стоп-лист, стоп, отписка | смотри ниже | внести ИНН в стоп-лист, больше ему не пишем |

Порядок шагов: портрет, список, отсев, обогащение, сигналы, письмо, черновики. Пропускать шаги нельзя: каждый следующий читает то, что записал предыдущий.

## Если аргумент пустой

Покажи человеку таблицу выше одним коротким списком и спроси, с какого шага начинаем. Если `config.json` ещё не заполнен, предложи начать с портрета.

## Где лежат скрипты и конфиг

Скрипты и конфиг ставятся в `~/.claude/tools/prodazhi/`. Рабочая папка человека может быть любой, поэтому путь всегда вычисляй, а не пиши руками:

```bash
PRODAZHI="$HOME/.claude/tools/prodazhi"; [ -d "$PRODAZHI/scripts" ] || PRODAZHI="$(pwd)"
ls "$PRODAZHI/scripts"
```

Конфиг один: `$PRODAZHI/config.json`. Никакого `config/icp.json` в проекте нет.

## Стоп-лист и отписка

Просьбу «не пишите мне» выполняет не вежливость, а таблица `stoplist`. Внеси ИНН и покажи человеку результат:

```bash
PRODAZHI="$HOME/.claude/tools/prodazhi"; [ -d "$PRODAZHI/scripts" ] || PRODAZHI="$(pwd)"
python3 "$PRODAZHI/scripts/stoplist.py" --db data/leads.db --add 7712345678 --reason "ответили стоп"
python3 "$PRODAZHI/scripts/stoplist.py" --db data/leads.db --list
```

После этого письмо этой компании не соберётся и в черновики не попадёт: проверка стоит и в `write_letter.py`, и в `drafts.py`.

## Чего делать нельзя

- Не выдумывай факты про компанию. В письмо идёт только то, что прошло проверку в `verify.py`.
- Не отправляй письма. Конвейер кладёт черновики, отправляет человек руками.
- Не пиши тем, кто в стоп-листе, и не убирай строку отписки из письма.
