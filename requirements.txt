# Чтение xlsx-выгрузки из реестра МСП. Всё остальное работает
# на стандартной библиотеке Python 3.9.
#
# ВАЖНО: openpyxl тут НЕ обязателен. В scripts/fns_rmsp.py встроен свой
# парсер xlsx на zipfile и ElementTree, и именно он идёт первым, а openpyxl
# остаётся страховкой на случай смены формата отчёта.
#
# Почему нижняя граница 3.0.6: у openpyxl в режиме read_only есть известная
# ловушка. Если в xlsx некорректно указан размер листа (<dimension>),
# библиотека доверяет этому полю и отдаёт одну строку вместо всей выборки.
# Лечится вызовом reset_dimensions(), он появился в 3.0.6.
#
# На файлах от rmsp.nalog.ru мы этого НЕ воспроизводили: распаковка отдала
# все строки. Граница версии стоит как бесплатная страховка, а не потому,
# что проблема замерена у нас.
openpyxl>=3.0.6
